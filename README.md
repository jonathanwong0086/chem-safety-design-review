# 化工安全设施设计专篇评审诊断技能

> **chem-safety-design-review** — 对标政府专家上会审查水平的化工建设项目"安全设施设计专篇"专家级评审诊断技能。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Standard: AQ 3066-2025](https://img.shields.io/badge/标准-AQ%203066--2025-green)](https://www.mem.gov.cn/)

## 概述

本技能用于对**化工建设项目安全设施设计专篇**（含中试专篇）进行专家级评审诊断，核心立场：

> 程序、文本、编辑方面的核查只是秘书级校稿；**专家级审查是工程师级的审查**，包括六个维度：章节完整性核查（逐章对照标准要求）、条款级适用性判断（这本标准适不适用这个项目）、数据闭环核验（四处数据是否同源一致）、关键计算独立复核（事故水池、消防水量等要重算）、危险辨识与设施映射（每项危险都要有对应设施并落到具体位号）、工艺纵深（重点监管工艺全流程自动化、SIL定级验证）。

输出 A/B/C 分级缺陷清单与通过性三档结论，支持：
- 专篇诊断、审查、校稿
- 专家意见落实核查
- 多版本修改对比
- 上会/报批通过性评估
- 企业对专家意见的修改回复复核

## 核心特性

### 三层证据架构 (L1→L2→L3 自动降级)

| 层级 | 证据源 | 触发条件 | 证据等级 |
|------|--------|----------|----------|
| **L1** | WeKnora 内网规范库 (向量+关键词混合检索) | 凭证已配置且 API 可达 | 最高 |
| **L2** | 本地规范库全文检索 (150本标准 markdown) | 仅当 L1 完全不可用时启用 | 高 |
| **L3** | 内置锚点卡 (高频硬值精选) | L1/L2 均不可用 | 兜底,值一律标 `[需复核]` |

**断网/API 不可用时自动降级,无需手动切换。** 所有标准取值可追溯出处:
- L1 → `知识库标题#chunk索引`
- L2 → `文件路径:行号`
- L3 → `[需复核,来源:内置锚点卡]`

### 强制执行工序 (M1–M7)

- **M1**: 全文落盘可检索 (pandoc 导出,表格全量,禁止抽查)
- **M2**: 计算复核留痕台账 (可执行计算,非心算)
- **M3**: 法规时效搜索复核 (诊断当天对每本标准文号核现行有效性)
- **M4**: 程序要件清单核查 (安全条件审查意见书/备案证/资质/审查权限)
- **M5**: 跨文种联动 (安评/环评/HAZOP 错误沿传排查)
- **M6**: 评审标尺事前声明 (否决项判定阈值/证据等级)
- **M7**: 问题映射与颗粒度 (多版本对比输出"问题映射表")

### 十步工作流

1. **预处理落盘** → 2. **文种定性与属地** → 3. **证据层探测** → 4. **章节完整性对照** → 5. **危险辨识复核＋设施映射** → 6. **逐类设施符合性** → 7. **可计算项重算** → 8. **数据闭环＋图文一致** → 9. **意见三段闭环** → 10. **A/B/C 分级输出**

每步标注【输入/动作/产出/留痕】,步骤 4/6/7 按需加载对应 reference。

## 快速开始

### 环境配置

可选配置环境变量以启用 L1/L2 证据层（不配置则自动降级到 L3）。**推荐方式**：创建技能专用配置文件 `~/.claude/chem-safety.env`，内容如下：

```bash
# L1: WeKnora 内网规范库（优先）
export WEKNORA_BASE_URL="https://your-weknora-host/api/v1"
export WEKNORA_API_KEY="your-api-key"
export WEKNORA_KB_IDS="kb-id-1,kb-id-2"  # 专篇相关知识库 id，逗号分隔

# L2: 本地规范库（断网兜底）
export CHEM_STD_LIB="/path/to/weknora-input-v3/documents"
```

脚本 `scripts/weknora_probe.sh` 会主动读取此文件，在非交互 shell 下也能正确加载配置。如果文件不存在，脚本会尝试从当前环境变量读取；都没有则自动降级到 L3。

### 使用示例

```bash
# 1. 载入证据探测与检索函数
source scripts/weknora_probe.sh

# 2. 探测证据等级（打印 L1/L2/L3 并导出 EVIDENCE_LEVEL）
chem_probe
# 输出示例: 本次证据等级: L1 / 配置来源: /c/Users/Admin/.claude/chem-safety.env

# 3. 按当前证据等级检索标准条款
chem_search "GBT50493 探测器 水平距离 释放源"

# 4. 开始专篇诊断（遵循 SKILL.md 十步工作流）
#    - 步骤4 加载 references/checklist-completeness.md
#    - 步骤6 加载 references/standard-anchors.md
#    - 步骤7 加载 references/calc-cards.md
#    - 步骤10 按 references/output-templates.md 各表填写数据到 JSON

# 5. 生成单个 Word 报告
#    把诊断数据填入 scripts/report_schema.json（可复制后修改）
python scripts/build_report.py 诊断数据.json 诊断报告.docx
#    产出单个 .docx，含封面、结论摘要、分项表、A/B/C 缺陷清单，用 Word 直接打开
```

## 专篇专有核查清单 (9 条高频缺陷模式)

1. 跨文种基础数据互锁但不免检 (辨识类计算独立重算,不采信安评)
2. 评审闭环失信点排查 (回复"已核实"的点名项终稿穿透)
3. 重大危险源辨识变更联动 (储量变更后重算,不得先下结论后凑储量)
4. 辨识表内部规则 (同物质双列双计/易燃液体类别 vs 火灾类别互证)
5. 储量多口径互证 (原辅料表/设计范围/辨识/一致性说明四处同源)
6. 意见子项级缺项 (复合意见拆为可核查子项逐条核销)
7. 法定辨识清单穿透 (易制毒/高毒物品/监控化学品对照目录原文)
8. 配伍与混存论证 (火灾类别悬殊物料同罐组,泄漏混合风险论证)
9. 编辑质量核查 (过期依据/标准号错字/表编号交叉引用错误)

## A/B/C 缺陷分级

| 分级 | 定义 | 示例 |
|------|------|------|
| **A类** (结论性/否决性) | 颠覆性错误 | 核心设施章缺项、标准误用致整表无效 (精细化工错用石油化工标准)、辨识计算错误、程序硬伤 (无审查意见书/资质不符)、危险无对应设施 |
| **B类** (重要) | 影响结论准确性 | 依据/概况/结论章关键内容缺失、数据闭环断裂、计算偏差、图文不一致 |
| **C类** (一般) | 编辑质量 | 错字、编号、单位缺失、目录空挂 (涉资质/文号程序硬伤升 A/B) |

## 通过性三档结论

1. **可上会/通过** — 无 A 类缺陷,B 类已整改或不影响核心结论
2. **修改后上会/有条件通过** — 无 A 类或 A 类可限期整改,须列明整改项清单
3. **不具备上会条件/退回** — 存在 A 类颠覆性缺陷

## 中试专篇特有要点

- 小试总结与放大论证附件 (附件缺失即"工艺稳定"结论悬空)
- 机械化换人自动化减人对照表、反应安全风险评估采纳情况表
- 重点监管工艺控制方案须对照监管要求逐条列表给出仪表位号/报警值/联锁动作
- 依托在建/未验收设施时,"验收合格后投用"须上升为结论性前置条件

## 诊断红线 (实证教训)

- ❌ **两文种同错≠相互印证** — 安评错误逐位沿传入专篇,辨识类计算必须独立重算
- ❌ **同一机构的错误呈技术传统性** — 发现某类错误模式后按模式排查,非个案排查
- ❌ **空表识别** — 模拟计算类表格必须打开核对有无数据行 (仅表头而正文"由以上数据可知"记缺项)
- ❌ **模板残留扫描** — 出现本项目不存在的介质/装置名/设施,相关结论无效
- ❌ **数值几何可行性** — 储量/供气量先做"物理上可能吗"检验 (罐容×密度×充装系数×台数几何上限)
- ❌ **证据等级自省** — L3 下任何"合标/超标"判断都是待复核初判,不得作为终审否决唯一依据
