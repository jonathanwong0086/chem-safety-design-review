# 专篇计算复核公式卡

> 用途：步骤7加载。凡专篇给出计算过程与结论的，按对应卡片复核：**输入项完整性→公式适用条件→数值复算→结论保守性**。每项入"关键计算独立复核表"（M2 留痕，模板见 output-templates.md）。
>
> **复算铁律**：用可执行计算（非心算）；公式系数以标准原文为准（L1/L2 检索确认），本卡系数标 `[需复核]` 的须核现行标准。先做**几何可行性检验**（物理上可能吗），再做精算。

## 卡1 事故水池/事故水量（GBT50483-2019 第6.6节）

- **适用边界**：化工建设项目用 **GBT50483-2019 第6.6节**；**SH/T3024-2017 仅限石油化工，误用于精细化工则整项无效**（规程3基准案例）。
- **公式**：`V事故水 = V1 + V2 + V3 − V转输`
  - V1 = collect 的物料泄漏量（最大单罐/最不利工况）
  - V2 = 事故时消防水量（消防水强度×延续时间×同时作用系数）
  - V3 = 降雨量（事故历时对应降雨，按当地暴雨强度）
  - V转输 = 事故过程中可转输至下游处理的量（有可靠转输能力方可扣减）
- **核查点**：①四项是否齐全（漏 V3 降雨、漏 V2 消防水最常见）；②V转输 扣减是否有可靠依据；③消防水量与消防章节口径一致（数据闭环）；④系数取值 `[需复核 GBT50483 原文]`。
- **检索**：`GBT50483 事故水 容积 6.6`、`事故排水 收集 计算`。

## 卡2 消防水量（GB50974 等）

- **适用**：GB50974（消防给水及消火栓）＋各灭火系统标准（GB50151泡沫/GB50219水喷雾/GB50084喷淋）。
- **公式**：`Q消防总 = Q室外消火栓 + Q室内消火栓 + Q泡沫/水喷雾/喷淋 + Q冷却水`
  - 室外消火栓：L/s 需 **×3.6×t(h)** 换算为 m³ 后相加（高频漏换算）。
  - 罐体冷却面积：`A = π×D×H`（**用直径 D，非半径**，高频错误）；冷却水量 = 冷却强度 × A × 延续时间。
- **核查点**：①正文计算值、结论值、汇总表值**三处一致**（数据闭环）；②火灾延续时间取值按物料/设施查表 `[需复核]`；③供给强度按系统标准表 `[需复核]`；④一次灭火用水量取各工况最大值口径。
- **检索**：`GB50974 消防用水量`、`火灾延续时间`、`冷却水 供给强度`。

## 卡3 可燃/有毒气体探测器布点（GBT50493-2019）

- **适用**：GBT50493-2019。
- **核查点（非等式，是覆盖判定）**：
  - 每个释放源是否被探测器覆盖（4.1.3 应布点场所逐一核）。
  - 水平距离限值 `[原文核校]`：露天可燃≤10m/有毒≤4m（4.2.1）；封闭可燃≤5m/有毒≤2m（4.2.2）；防火堤内可燃≤10m/有毒≤4m（4.3.1）；铁路栈台≤10m（4.3.4）；明火炉边5~10m（4.4.1）。
  - 比空气轻气体：厂房最高点加设（4.2.3）。
  - 报警值一/二级区分；区域警报器用二级信号启动（5.3.1）。
- **复算方式**：按布置图量测每个释放源到最近探测器的水平距离，逐点比对限值；统计漏覆盖释放源。
- **检索**：`GBT50493 探测器 水平距离 释放源`。

## 卡4 氮气/仪表风用量（惰性化、密封、吹扫）

- **适用**：无单一国标等式，按工艺物料衡算＋设备制造商数据；核**几何可行性**与**同时系数**。
- **核查点**：
  - 氮气：用于惰性保护/置换/输送的量，是否按最大同时用氮工况叠加；储罐大呼吸+小呼吸补氮量是否计入；纯度与露点是否满足工艺。
  - 仪表风：按气动执行机构/切断阀数量×单台耗气×同时动作系数，是否留裕量；**气源压力低报警＋联锁**是否设置（专有清单6：气动切断阀失气动作方向依赖气源可靠性）。
  - **几何可行性**：供气量 vs 用气量峰值，物理上是否满足；空压机/制氮机能力与储罐缓冲是否匹配。
- **红线**：无惰性气体封闭空间不应出现"氧含量检测"表述（模板残留 N3，见 checklist 4.11）。
- **检索**：`制氮 用量 惰性`、`仪表空气 耗气量`、`气源 低压 联锁`。

## 卡5 储量几何上限（重大危险源辨识基准）

- **适用**：一切涉储罐/储存量的辨识与防火/防溢计算的**前置校验**（M2 强制）。
- **公式**：`最大储存量 = 单罐几何容积 × 介质密度 × 充装系数 × 在用台数`
  - 介质密度取正文理化性质表（勿用水的密度默认）。
  - 充装系数按介质与罐型 `[需复核]`（常压/压力/低温储罐不同）。
  - **应急罐（1用1应急）须计入储存量与辨识**（专有清单5，高频漏计）。
- **核查点**：①原辅材料表/设计范围/辨识计算/一致性说明**四处储量同源**（专有清单5）；②依托与新建区分；③辨识临界量比对用**更正后储量**（专有清单3：不得先下"非重大变更"结论后凑储量）。
- **复算方式**：先算几何上限判断"物理上可能吗"，再与报告取值比对；差异>5% 即列问题。
- **检索**：`储罐 容积 充装系数`、`重大危险源 临界量 储存量`。

## 卡6 重大危险源辨识（GB18218，独立重算）

- **适用**：GB18218（复核现行版）。**不采信安评，独立重算**（红线：两文种同错≠互证）。
- **公式**：`S = Σ(qi / Qi)`，S≥1 构成重大危险源；分级按 R 值/校正系数法。
  - qi = 各危化品实际存在量（取最大在用量，含应急罐）。
  - Qi = 对应临界量，**取目录中最小适用临界量**（专有清单1/4：临界量取最小）。
- **核查点**：①同物质双列双计排查（专有清单4）；②临界量取值逐一对照 GB18218 附表原文 `[需复核现行版]`；③校正系数 β/α 取值依据；④分级结论（一~四级）算术复核。
- **红线案例**：乙腈临界量放大115倍、甲基肼 J1/J2 矛盾、浓硫酸系统性遗漏——均自安评沿传，专家须独立拦截。
- **检索**：`GB18218 临界量`、`重大危险源 分级 校正系数`。

## 卡7 外部安全防护距离（GBT37243-2019 / GB36894-2019）

- **适用**：GBT37243-2019（确定方法）＋GB36894-2019（风险基准）。
- **核查点（非简单等式，是QRA闭环）**：
  - 是否经**定量风险计算（QRA）**得出，而非直接给结论（高频：无计算即下结论）。
  - 防护目标（居住区/学校/医院/相邻企业）辨识是否齐全。
  - 个人风险≤基准值、社会风险 F-N 曲线在可接受区（GB36894 限值 `[需复核]`）。
  - α人口取值是否有实际人口数据支撑（红线：分母/比值假设异常须敏感性重算）。
- **复算方式**：核输入（源项、频率、后果）→核模型适用性→核风险值 vs 基准限值→核防护目标覆盖。
- **检索**：`GBT37243 外部安全防护距离`、`个人风险 社会风险 基准`、`QRA 防护目标`。

## 通用复算工序（每卡适用）

1. **输入项完整性**：公式各项是否齐全，缺项即列问题（漏项常使结果偏小、偏不安全）。
2. **公式适用条件**：标准适用范围（行业属性）、工况假设是否成立。
3. **数值复算**：可执行计算逐步复现，与报告值比对；系数以标准原文为准。
4. **结论保守性**：取值口径是否取最不利/最大值；结论是否偏宽松（M6：宽松结论须书面解释）。
5. **数据闭环**：同一物理量在正文/结论/汇总表/图纸多处是否一致（≥2次必一致）。
6. **出处留痕**：每项复算填入"关键计算独立复核表"，附证据源（L1/L2/L3）。
