# 规范库映射索引与检索封装

> 用途：这个文件干三件事——（1）告诉本技能内网规范库里**有哪些标准**（150 本，六大专业）；（2）提供三层证据架构的**检索封装**；（3）列出**法规时效核查**的要点。第 3 步（证据探测）和第 6 步（设施符合性）加载。

## 一、可配置参数（都不写死在代码里）

这四个参数写在配置文件 `~/.claude/chem-safety.env` 里（脚本会主动读取，不依赖 `~/.bashrc`）：

| 参数 | 含义 | 缺省时的行为 |
|---|---|---|
| `WEKNORA_BASE_URL` | WeKnora 接口根地址（如 `http://主机:端口/api/v1`） | 没设就跳过 L1 |
| `WEKNORA_API_KEY` | WeKnora 接口密钥 | 没设就跳过 L1 |
| `WEKNORA_KB_IDS` | 专篇相关的知识库 id，多个用逗号分隔 | 没设时，L1 会先列出知识库让用户选，或者全库跨搜 |
| `CHEM_STD_LIB` | 本地规范库 `documents/` 目录的路径（如 `.../weknora-input-v3/documents`） | 没设或目录不存在就跳过 L2 |

诊断开始时，如果 L1、L2 都因为参数缺失用不了，要明确提示用户："没有配置 WeKnora 凭证，也没有提供本地规范库路径 `CHEM_STD_LIB`；本次将以 L3 内置锚点卡兜底，所有标准数值上会前必须复核。是要继续，还是先补配置？"

## 二、检索封装（三层）

### L1：WeKnora（本技能直连接口）

本技能通过内置的 `wk_api`、`wk_search`、`wk_hybrid` 三个函数，直接调用 WeKnora 接口完成检索（混合检索、跨库检索），不需要另外安装独立的 weknora 技能。如果环境里恰好装了 weknora 技能，也可以改用它来做，但那不是必需的。

内置的检索函数（已封装在 scripts/weknora_probe.sh 里）：

```bash
wk_api() {  # method endpoint [json-body]
  curl -s -m 20 -X "$1" "$WEKNORA_BASE_URL/$2" \
    -H "X-API-Key: $WEKNORA_API_KEY" \
    -H "Content-Type: application/json" \
    -H "X-Request-ID: $(date +%s)" \
    ${3:+-d "$3"}
}
# 跨库语义检索（专篇场景常用）：
wk_search() {  # "query" 
  local ids_json
  ids_json=$(echo "$WEKNORA_KB_IDS" | awk -F, '{for(i=1;i<=NF;i++)printf "%s\"%s\"",(i>1?",":""),$i}')
  wk_api POST "knowledge-search" "{\"query\":\"$1\",\"knowledge_base_ids\":[$ids_json]}"
}
# 单库混合检索（注意：GET 但需 JSON body）：
wk_hybrid() {  # kb_id "query" match_count
  wk_api GET "knowledge-bases/$1/hybrid-search" "{\"query_text\":\"$2\",\"match_count\":${3:-5}}"
}
```

接口返回条款文本、匹配分数、知识库标题、chunk 序号。引用出处就写成"知识库标题#chunk 序号"。

### L2：本地规范库全文检索（只在断网时兜底）

用 Grep 工具或 rg，对 `$CHEM_STD_LIB` 目录下目标标准的 md 文件检索。定位标准文件时，用标准编号去匹配目录名：

```bash
# 例：查 GB50058 里爆炸危险区域划分的相关条款
rg -n "爆炸危险区域|区域划分|2区" "$CHEM_STD_LIB"/*/GB50058*/*.md
```

引用出处写成"文件相对路径 + 行号或章节号（## x.x）"。标准正文里保留了原始的章节号标题，可以直接定位到条款。

### L3：内置锚点卡

L1、L2 都用不了时，读 [standard-anchors.md](standard-anchors.md)，取值一律标注"需复核，来源是内置锚点卡"。

## 三、检索关键词的写法

- 优先用**标准编号加设施术语**的组合（比如"GBT50493 探测器 安装高度"），命中率比纯自然语言高。
- 核查数值时，检索**条款的特征词**（比如"不应小于""不宜大于""严禁""临界量""释放源"）。
- L1 语义检索和 L2 精确检索的关键词可以不一样：L1 可以用问题式（"可燃气体探测器距释放源多远"），L2 用词组式（"释放源 半径 探测器"）。

## 五、法规时效核查要点（M3 强制，引用前必须搜索复核）

> 下面这些是编写时点的快照，**会随时间老化**。诊断当天，要对专篇引用的每一本标准文号做现行有效性复核：L1 或 L2 可用时，以规范库清单里标的版本年和现行状态为准，并交叉搜索确认；L3 时只能凭下表判断，必须显著标注"待复核"。

### 高频"新旧版本陷阱"（专篇依据清单常见错误）

- **GB55037-2022 建筑防火通用规范** + **GB55036-2022 消防设施通用规范**：强制性工程建设规范，与 GB50016、GB50974 等并行，专篇依据清单不得只列旧规范而漏通用规范；冲突时以通用规范从严。
- **GB51283-2020 精细化工企业工程设计防火标准**：精细化工项目防火间距/分区应优先适用，不得错用 GB50160（石油化工）。库内两者都有，注意项目行业属性匹配。
- **SHT3006、SHT3081** 库内各有两个版本年（2012/2024、2019/2025），引用须核对采用版本，禁止新旧并列。
- **GBT21109 系列**：功能安全，.1-2022 已替代旧版，.2 有 2007/2023 两版，.3-2026（对应 IEC61511-3）为 SIL 定级指南——SIL 相关引用须用现行版。
- **GB50974-2014** 的标准全称是"消防给水及消火栓系统技术规范"（规范库清单里写的"给排水"是录入偏差，以标准原文为准）。
